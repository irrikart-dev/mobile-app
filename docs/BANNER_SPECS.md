# irriKart app — banner sizes for the design team

All sizes are exported at **@3x** (what modern Android phones use). Send PNG,
JPG or WebP, sRGB, under 400 KB each. Don't bake any app text (titles,
buttons) into the images — the app draws those itself.

## 1. Intro / onboarding banners (first-open screens)

| | |
|---|---|
| Count | 5 (one per intro screen; we can use fewer) |
| Size | **1080 × 1080 px** (square, 1 : 1) |
| Safe area | Keep everything important inside the **centre 864 × 864 px** (80%) |
| Corners | The app rounds the corners (≈ 84 px radius at this size) — keep content out of the corners |
| Background | Full-bleed art is fine; a light background reads best in both light and dark mode |
| Text below the banner | Drawn by the app — send us the title (≤ 40 characters) and one line of description (≤ 110 characters) per screen if you want to change the current copy |

Current screens, for reference: *The right irrigation gear, made simple* ·
*Everything your farm needs* · *Fast, secure payments* · *Track every
delivery* · *Buying in bulk?*

## 2. Sign-up / sign-in banner

| | |
|---|---|
| Size | **1170 × 540 px** (≈ 2.17 : 1), full screen width |
| Safe area | Keep important content inside the **centre 900 px** width — narrower phones crop the sides |
| Background behind it | Deep green **#1F5C3A → #163F29** (top to bottom); a transparent PNG blends in, or supply a full-bleed image |
| Logo | Not part of the banner — the white irriKart logo sits above it automatically |

## 3. Home screen carousel (optional, if you want image banners)

| | |
|---|---|
| Size | **1080 × 560 px** (≈ 1.93 : 1) |
| Safe area | Centre 960 × 480 px; the app rounds corners (≈ 60 px) and adds a "Shop now" button bottom-left, so keep the bottom-left 380 × 140 px clear |
| Count | 3–5 |

Today these slides are drawn in-app with live product photos; switching to
image banners is a small change on our side once the artwork arrives.
